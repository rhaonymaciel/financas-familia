# Finanças Família Maciel

App de controle financeiro familiar — React + Supabase.

## Deploy no Vercel

1. Faça upload desta pasta no GitHub:
   - Acesse github.com → New repository → "financas-familia"
   - Clique em "uploading an existing file" → arraste toda a pasta `src`, `public`, `package.json`, `.gitignore`
   - Commit changes

2. Acesse vercel.com → New Project → importe o repositório do GitHub

3. Clique em Deploy — pronto!

## Uso

- **Início**: dashboard do mês com receitas, despesas e gráficos
- **Extrato**: todos os lançamentos com filtros por tipo
- **Lançar**: adicionar receita ou despesa manualmente
- **Fatura PDF**: importar JSON extraído pelo Claude a partir do PDF da fatura
- **Orçamento**: definir e acompanhar limites por categoria
